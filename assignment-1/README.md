# Final Fantasy See 'N' Say Story Generator

A browser-based story generator inspired by the classic See 'N' Say toy. Pick a character, an action, a thing, a location, and an ending, and it builds a silly FF-themed story. Includes text-to-speech, per-game logos, and per-game background themes.

Built as a JavaScript assignment for the Computer Programming program at Georgian College. Not affiliated with Square Enix.
